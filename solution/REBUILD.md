# Как собрать журнал заново

Код не требуется: инструмент — агент с полным запросом [prompt-v2.md](prompt-v2.md).

1. Создайте отдельную папку вне этого репозитория. Скопируйте туда только выбранный вход: `data/chat.md` либо `data/chat-without-second-reaction.md`, под именем `chat.md`. Запрос `solution/prompt-v2.md` скопируйте под именем `prompt.md`.
2. Откройте новую сессию агента без истории этой работы. Предоставьте доступ только к этим двум файлам; не давайте ему читать весь репозиторий, журналы, review.md или скрытую легенду.
3. Попросите выполнить запрос из `prompt.md`, используя только `chat.md`. Сеть не нужна. Нужны чтение UTF-8 и запись Markdown. Срез — 30.09.2026 18:00 МСК. Сообщения обозначены Mnnn, реакции — Rnnn с автором, временем и адресатом target.
4. Сохраните полный первый `journal.md` и `run.md` до сверки с ответами. В протоколе укажите модель (если известна), фактически прочитанные файлы, инструменты, дату и ограничения.
5. После фиксации результата проверяющий сверяет его с отдельно хранимой легендой. Для изменённого входа учитывается отсутствие одного подтверждения. Полнота, статусы, отмены, неявное согласование и неподтверждённые темы проверяются по существующим сообщениям и реакциям. Ответственный и срок должны быть отдельными полями. Правки оформляются новой версией, не заменой первого результата.

Первоначальные прогоны выполнены 4 октября 2026 в Codex на базе GPT-6; точный вариант модели не сообщён. Протоколы опубликованы рядом с результатами. Изоляция исходных прогонов заявлена инструкцией чтения, без файловой песочницы; отсутствие доступа к ключу независимо не доказано.

На чужом чате сначала примените этот запрос без правок, сохраните первый результат и лишь затем сверяйте его с легендой автора. Отдельно зафиксируйте случаи «решили X, делают Y», если они присутствуют. Изменения запроса и ручную работу записывайте после исходной попытки. Текущие материалы этот этап не подтверждают.

Один исходный и один изменённый прогон не доказывают стабильность на повторах или переносимость на другие чаты.
